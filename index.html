ルート登録

よく行く現場の名前を登録します。入力画面で名前をタップすると、そのルートの行が追加されます。並び順は「上へ」「下へ」で変えられます。

名前を変えても、削除しても、すでに保存した記録はそのまま残ります。

📝 記録のしかた

  1. 「入力」で、その日の日付・開始・終了・休憩を入れます。
  2. 回ったルート（現場）を追加します。登録済みの名前をタップするか、「＋ ルートを追加」で名前を入力します。
  3. ルートごとに件数を入れます。その日の合計は自動で出ます。
  4. 体調とメモを入れて「保存する」を押します。

リストにない現場は、登録しなくてもそのまま保存できます。次も使うなら「この名前を登録」を押してください。

名前の追加・変更・削除・並べ替えは「ルート」タブで行います。ここでの変更は、過去の記録の名前を書き換えません。

以前の記録（現場名が1つ）は、アプリを開いたときに自動で引き継ぎます。同じ日で開始・終了・休憩が同じ記録は1日にまとまります。時刻が違う記録は別のまま残るので、消えることはありません。

📲 ホーム画面に追加する

ホーム画面に追加すると、アプリのように全画面で開けて、電波がなくても使えます。

✅ いまはホーム画面のアプリとして開いています。

iPhone（Safari）

  1. このページを Safari で開く
  2. 画面下の 共有ボタン（□に↑のマーク）をタップ
  3. メニューを下にスクロールして 「ホーム画面に追加」 をタップ
  4. 右上の 「追加」 をタップ

※LINEなどのアプリ内ブラウザでは追加できません。右下のメニューから「Safariで開く」を選んでください。

Android（Chrome）

  1. このページを Chrome で開く
  2. 右上の ︙（メニュー） をタップ
  3. 「アプリをインストール」 または 「ホーム画面に追加」 をタップ
  4. 確認画面で 「インストール」（または「追加」）をタップ

💾 データについて

記録はこのスマホの中だけに保存され、外部には送信されません。ほかの人と共有されることもありません。

  • ブラウザの「履歴・データを消去」をすると記録も消えます。
  • Safariで使った記録と、ホーム画面のアプリで使った記録は別々になる場合があります（iPhone）。追加した後はホーム画面のアプリから使ってください。
  • 機種変更の前には「集計」→「バックアップ」で保存しておき、新しいスマホで「復元」してください。むかしの形式のバックアップも読み込めます。
