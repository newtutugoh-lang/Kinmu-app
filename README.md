# 勤務記録

毎日の勤務時間と、その日に回ったルート（現場）ごとの件数・体調を記録して、月ごとに集計・Excel出力できるアプリです。スマホのブラウザで開き、ホーム画面に追加して使います。

## 開き方

https://newtutugoh-lang.github.io/Kinmu-app/

## ホーム画面に追加する

**iPhone（Safari）**

1. 上のURLをSafariで開く
2. 画面下の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 右上の「追加」をタップ

**Android（Chrome）**

1. 上のURLをChromeで開く
2. 右上のメニュー（︙）をタップ
3. 「アプリをインストール」または「ホーム画面に追加」をタップ
4. 「インストール」（または「追加」）をタップ

追加したあとは、ホーム画面のアイコンから開いてください。

## 記録のしかた

1日につき1件の記録です。日付・開始・終了・休憩・体調・メモは、その日の分として1回入れます。

回ったルート（現場）は行を分けます。それぞれの行に名前と件数を入れます。その日の件数は、行の合計です。

- 「＋ ルートを追加」で行を増やします。いらない行は「削除」です。
- よく行くルートは、画面下の「ルート」で登録できます。名前の変更、削除、上へ・下へでの並べ替えができます。
- 入力画面では、登録した名前をタップすると行が追加されます。
- リストにない現場は、その場で名前を入力して保存できます。「この名前を登録」を押すと、次からタップで選べます。

以前の記録（現場名が1つ）は、アプリを開いたときに自動で引き継がれます。同じ日で開始・終了・休憩が同じ記録は1日にまとまります。時刻が違う記録は、別の記録のまま残ります。

むかし書き出したJSONバックアップも、そのまま「復元（読み込み）」で読めます。

## データはこのスマホだけ

記録は、このスマホのブラウザの中だけに保存されます。サーバーには送られません。

ブラウザのデータを消すと記録も消えます。機種変更の前など、アプリの「集計・出力」にあるバックアップの「保存（書き出し）」でJSONファイルを保存してください。戻すときは「復元（読み込み）」を使います。
