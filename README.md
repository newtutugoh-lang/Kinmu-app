# 勤務記録

毎日の勤務時間・件数・体調を記録して、月ごとに集計・Excel出力できるアプリです。スマホのブラウザで開き、ホーム画面に追加して使います。

## 開き方

https://newtutugoh-lang.github.io/Kinmu-app/

## ホーム画面に追加する

**iPhone（Safari）**

1. 上のURLをSafariで開く
2. 画面下の共有ボタン（□に↑）をタップ
3. 「ホーム画面に追加」をタップ
4. 右上の「追加」をタップ

**Android（Chrome）**

1. 上のURLをChromeで開く
2. 右上のメニュー（︙）をタップ
3. 「アプリをインストール」または「ホーム画面に追加」をタップ
4. 「インストール」（または「追加」）をタップ

追加したあとは、ホーム画面のアイコンから開いてください。

## データはこのスマホだけ

記録は、このスマホのブラウザの中だけに保存されます。サーバーには送られません。

ブラウザのデータを消すと記録も消えます。機種変更の前など、アプリの「集計・出力」にあるバックアップの「保存（書き出し）」でJSONファイルを保存してください。戻すときは「復元（読み込み）」を使います。
